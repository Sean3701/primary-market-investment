# 报告结构与更新规则

## 快速初筛

先给判断，约一至两屏；表格按需使用，不为填满模板制造结论。

```text
公司 / 分析日期 / 数据截至日 / 材料版本 / 分析范围
建议动作：优先接触、推进尽调、补充材料、持续跟踪或放弃
一句话说明生意与核心判断

阶段：声称轮次；实际证据支持的成熟度；判断局限
项目吸引力：核心理由，避免综合打分
证据充分程度：哪些已核实，哪些仅公司自述
交易吸引力：价格条款是否已知；可以或不能判断的部分
个人适配：已知条件；待确认部分

三条以内核心投资逻辑（附证据和成立条件）
最重要的失败风险与反对理由
优先问的五个问题、需要的三类材料；按实际缺口可减少
改判条件：看到什么证据会推进、等待或放弃
```

引用关键数据用简短来源 ID，后附证据表和原文定位。有网络研究时，给支持相关陈述的直接链接与日期。初筛有简单估值算式也要执行工具，不默认省去核验。

## 深度研判

首页沿用初筛摘要；正文按实际重要性展开：

1. 生意、客户与阶段：需求和付费证据；市场规模计算路径；为何现在。
2. 产品、技术与竞争：替代方案、可复制性、优势形成及衰减机制。
3. 团队、诚信与治理：能力与实际结果；股权与利益一致性；关键人风险。
4. 经营质量与资金：收入/订单/回款、单位经济、现金与负债、融资用途、下一节点及资金缺口。
5. 价格、条款与回报：口径、方法、情景和敏感性；资本结构与分配机制；无法估计处说明缺口。
6. 投资逻辑与反证：核心假设、验证方法、推翻证据；最强看空论据。
7. 行动与个人适配：推进条件、出资前必须解决的问题、等待节点、适配未知项。

附录：材料索引、证据台账、数值与计算、优先尽调问题。不得把“未发现问题”写成“已排除问题”。

## 更新判断

先读取旧报告或用户提供的旧结论，保留其日期、版本和假设。没有旧依据则不能声称意见发生变化。

| 核心判断或假设 | 旧状态/出处 | 新证据/出处 | 变化类型 | 当前状态 | 对建议影响 |
|---|---|---|---|---|---|

变化类型：经营事实 / 证据纠正 / 模型假设 / 价格与条款 / 个人偏好 / 仅措辞。
假设状态：支持 / 待验证 / 弱化 / 已推翻。未补证不自动升级为支持。

如输入影响模型，重算回报和敏感性；经营改善不必然抵消涨价。说明建议维持或改变的原因及下个验证节点。保留旧版本，用户未要求时不覆盖或新增定期监控。

## 结论语言

使用“基于目前材料，建议……；成立条件是……；若……则改变判断”。有依据时明确表达负面判断，不以空泛免责声明替代分析。没有个人资料时明确项目判断可做、个人出资适配未定。
