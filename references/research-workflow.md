# BP 到首轮投资判断

## 材料地图

登记文件名、版本、材料日期、数据截至日、总页数及不可读页。PDF 用物理页码，印刷页码可并列。文本提取保留页界；核看财务表、市场图、团队、股权融资及关键产品页面。纯图片页不是空白，OCR 数字与图中单位、坐标轴、脚注复核；不能确定则标记未知。

全文读完再定结论，封面和融资页只用于建立地图。逐页记录重要主张与疑点，不重抄每页。PPTX 或表格补件按可用工具读取，不能假称已看图。无材料时索取 BP，已有可用部分先分析并指出缺失影响。

## 经营机制与核验计划

先写清谁为什么付钱，公司如何获客交付，收入扣除什么成本才成为现金。区分使用者、采购决策者、预算方与付款方。找两三个关键价值驱动变量，再选阶段与商业模式模块。

拆解：主张 → 成立所需证据 → 已有证据 → 反例 → 判断影响。市场大、政策支持、名牌股东、技术先进必须连接到付费及本轮股东回报。

围绕决策问题检索，不凑搜索次数或来源数量：

| 问题 | 优先证据 | 限制 |
|---|---|---|
| 主体与团队 | 官方登记、公开任职、原始履历记录 | 同名主体需消歧，无访问权列缺口 |
| 客户与需求 | 客户自身披露、采购、产品价格和替代方案 | 中标/合作/POC不等于收入 |
| 市场与时机 | 官方统计、监管、招股文件、原始行业研究 | 注明地区年份口径，不把产业总额当收入池 |
| 技术与权属 | 原始论文、专利、测试和认证 | 专利/演示不证明量产或竞争优势 |
| 竞争与反证 | 对手原始披露、监管处理、裁判文书 | 区分事实、指控及传言 |
| 价格与退出 | 有日期条款的交易、上市可比披露、适用规则 | 不同权益、流动性及经营质量不能直接等同 |

当前事实、价格及监管法律须在线核验。打开原文而非仅搜索摘要，记录直接链接、发布日期、观察期间及访问日期。查不到、未查、访问受限、证据冲突分别标明。公司官网仍可能只是自述；来源级别与独立性分别判断。

对每条核心看多逻辑主动寻找反证或替代解释；未发现不等于不存在。无法获取原始来源时可使用可信二手资料，但标明限制。禁止伪造一手证据或引用未读取的页面。

核心判断可给出、剩余关键问题只能靠非公开材料或实地尽调解决时结束公开搜索，转入优先问题。有公开可解决的决策级冲突则继续定向核验。网络不可用时交付离线报告并说明未外部核验。

## 判断与交付

每个重要部分写结论、证据、推理、反例/缺口和投资含义；行业常识与公司事实分开。分别评价商业、证据、交易、个人适配，资料少不自动等于公司差，没有反证也不等于值得出资。

个人视角需回答：值得花时间继续研究吗？是否理解失败机制？锁定和跟投能否承受？小股东有什么信息及退出权？机会成本是什么？未知偏好保留判断，不预设风险承受能力。

长版完成后提取共享决策底稿：动作、阶段、关键数字口径、理由、风险、条件、未知项、下一步。短版只从底稿提炼；长版变化后同步短版。比较条件是否被删、风险是否变弱、缺口是否变成事实；检查引用、计算、日期、表格及文件链接。
